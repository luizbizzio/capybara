# Contributing to Capybara Game

Serve the repository root using `python -m http.server 8000` and open `http://localhost:8000`. The game entry point is [`index.html`](index.html). The audio clips are under [`public`](public).

## Review a change

- Play a round from start through the timer and score screen, then start another one. Check that scores and timers reset between rounds.
- Try mouse and touch input, rapid taps, and a narrow viewport. Check that audio starts after interaction and that the round remains playable when sound is unavailable.
- For changes to scoring, timing, or difficulty, describe the old and new behavior and include a short recording if the difference is easier to see in motion.

Use original or appropriately licensed assets and include their source and license in the pull request.
